Membuat Fitur Utama

Setelah pondasi routing, API, dan store siap, barulah fitur dibuat satu per satu. Chapter ini menjelaskan fitur besar yang ada di project.

1. Dashboard

Dashboard berada di src/pages/Dashboard.tsx. Halaman ini menampilkan ringkasan project dan task, recent tasks, upcoming deadlines, high priority tasks, dan latest updates.

  1. Komponen Dashboard dipanggil oleh route /dashboard.
  2. Dashboard memanggil useDashboardStore.
  3. Store memanggil dashboard service.
  4. Data summary ditampilkan sebagai stat card dan list task.

2. Project Sidebar

Sidebar berada di src/components/shared/Sidebar.tsx. Sidebar mengambil project dari endpoint sidebar lalu menampilkannya sebagai menu. User juga bisa membuat project baru dari tombol tambah di sidebar.

3. Project Board

Project board berada di src/pages/ProjectBoard.tsx. Halaman ini punya dua mode tampilan:

  • Board view: task dibagi dalam kolom Backlog, To Do, In Progress, Review, dan Done.
  • List view: task tampil dalam tabel/list dengan search, filter, dan pagination.

4. Drag and Drop Task

Board memakai library @hello-pangea/dnd. Saat pengguna menarik task ke kolom lain, fungsi onDragEnd membaca tujuan baru lalu memanggil moveTask. 

const taskId = Number(draggableId);
const newStatus = destination.droppableId as TaskStatus;
moveTask(taskId, newStatus, destination.index);

5. Task Dialog dan Detail Dialog

Untuk membuat atau mengubah task, project memakai dialog. Detail task memakai TaskDetailDialog agar pengguna bisa melihat informasi lebih lengkap tanpa pindah halaman.

6. Admin Users dan Teams

Halaman admin berada di src/pages/admin. Hanya user dengan role admin yang bisa membuka halaman ini.

  • Users.tsx: mengelola user.
  • Teams.tsx: mengelola team dan anggota team.

7. Notifikasi, Komentar, dan Attachment

Project juga punya service dan store untuk notifikasi, komentar, upload, dan attachment. Fitur ini membantu kolaborasi antar anggota tim.
