Urutan Pengerjaan dari Nol

Chapter terakhir ini merangkum urutan kerja yang bisa diikuti oleh pemula. Ikuti dari atas ke bawah agar tidak loncat terlalu jauh.

Tahap 1 - Pondasi Project

  1. Install Node.js dan npm.
  2. Buat project dengan Vite React TypeScript.
  3. Install dependency utama.
  4. Atur vite.config.ts.
  5. Atur src/index.css untuk Tailwind dan theme.
  6. Buat file .env untuk alamat API.

Tahap 2 - Struktur Aplikasi

  1. Buat folder components, pages, layouts, services, stores, types, dan utils.
  2. Buat route utama di src/App.tsx.
  3. Buat MainLayout dengan sidebar, header, dan outlet.
  4. Buat komponen kecil seperti Loading, Modal, NavItem, dan PageHeader.

Tahap 3 - Authentication

  1. Buat tipe data auth di src/types/auth.ts.
  2. Buat Axios client di src/lib/axios.ts.
  3. Buat auth.service.ts.
  4. Buat authStore.ts.
  5. Buat halaman Login dan Register.
  6. Buat ProtectedRoute.

Tahap 4 - Data Utama

  1. Buat tipe Project, Task, Team, User, Comment, Attachment, dan Notification.
  2. Buat service untuk setiap data.
  3. Buat store untuk setiap fitur.
  4. Pastikan setiap store punya loading dan error state.

Tahap 5 - Halaman dan Komponen Fitur

  1. Buat Dashboard.
  2. Buat Sidebar daftar project.
  3. Buat ProjectBoard mode board.
  4. Tambahkan drag and drop task.
  5. Tambahkan TaskList dengan search, filter, dan pagination.
  6. Buat TaskDialog dan TaskDetailDialog.
  7. Buat halaman admin Users dan Teams.
  8. Tambahkan notification bell, comment, upload, dan attachment.

Tahap 6 - Rapikan dan Uji

  1. Jalankan npm run dev untuk mencoba aplikasi.
  2. Jalankan npm run test.
  3. Jalankan npm run lint.
  4. Jalankan npm run build.
  5. Jalankan npm run preview untuk mengecek hasil build.

Alur Kerja Harian Developer

Saat mengerjakan project setiap hari, alurnya biasanya seperti ini: 

npm install
npm run dev

# ubah kode
# coba di browser

npm run test
npm run lint
npm run build

Ringkasan Akhir

Project ini dibangun dari pondasi Vite dan React, lalu disusun menjadi aplikasi lengkap dengan routing, layout, authentication, service API, store, dan halaman fitur. Jika mengikuti chapter dari awal, pembaca akan memahami bukan hanya cara menjalankan project, tetapi juga kenapa folder dan alur kodenya dibuat seperti sekarang.
