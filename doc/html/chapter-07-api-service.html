Koneksi API dengan Axios

Frontend tidak menyimpan data utama sendiri. Data seperti user, project, task, comment, dan notification diambil dari backend API. Project ini memakai Axios untuk mengirim request.

1. Konfigurasi Axios

File src/lib/axios.ts membuat object api. Semua service memakai object ini agar base URL, header, cookie, dan error handling konsisten. 

export const api = axios.create({
  baseURL: normalizeBaseURL(import.meta.env.VITE_API_URL),
  headers: {
    "Content-Type": "application/json",
  },
  withCredentials: true,
});

2. Base URL

Fungsi normalizeBaseURL memastikan alamat API selalu berakhir dengan /api/v1. Jadi jika developer mengisi http://localhost:8000, aplikasi akan mengubahnya menjadi http://localhost:8000/api/v1.

3. Request Interceptor

Request interceptor menambahkan header Authorization jika access token tersedia. Dengan begitu, service tidak perlu menambahkan token satu per satu. 

api.interceptors.request.use((config) => {
  if (accessToken) {
    config.headers.Authorization = `Bearer ${accessToken}`;
  }
  return config;
});

4. Response Interceptor

Jika backend mengembalikan status 401, artinya access token mungkin sudah habis. Aplikasi mencoba memanggil /auth/refresh untuk mendapatkan access token baru.

Jika refresh berhasil, request yang gagal tadi dicoba ulang. Jika refresh gagal, user dibersihkan dari aplikasi dan diarahkan ke login.

5. Service per Fitur

Folder src/services berisi fungsi untuk setiap area fitur.
