Gambaran Project

Project ini adalah aplikasi web untuk mengatur pekerjaan. Di dalamnya ada login, dashboard, project, task, team, user admin, notifikasi, komentar, dan attachment. Nama tampilan aplikasinya adalah TaskFlow.

Apa yang Dibangun?

Bayangkan sebuah tim sedang mengerjakan banyak pekerjaan. Mereka perlu tempat untuk melihat daftar project, membagi task, memindahkan task dari "To Do" ke "In Progress", melihat deadline, dan mengelola anggota tim. Aplikasi ini dibuat untuk kebutuhan itu.

Bagian Frontend dan Backend

Project ini adalah bagian frontend. Artinya, project ini bertugas menampilkan halaman dan menerima interaksi dari pengguna. Untuk menyimpan data, frontend mengirim request ke backend API.

Bagian Tugas
Frontend Menampilkan UI, form, tombol, daftar project, board task, dan dashboard.
Backend API Menerima request, menyimpan data, memeriksa login, dan mengirim data kembali.

Teknologi yang Dipakai

  • React: membuat tampilan dari komponen kecil.
  • TypeScript: membantu menangkap kesalahan tipe data lebih awal.
  • Vite: menjalankan project saat development dan membuat build production.
  • Tailwind CSS: membuat style dengan class utility.
  • React Router: mengatur perpindahan halaman.
  • Zustand: menyimpan state global seperti user, project, dan task.
  • Axios: mengirim request ke backend API.
  • React Hook Form: membantu mengelola sebagian form, seperti form project, task, team, dan user.
  • Vitest: menjalankan test.
Di project saat ini, React Hook Form belum dipakai di semua form. Form Login, Register, dan Profile masih memakai state React manual, sedangkan beberapa dialog fitur sudah memakai React Hook Form.

Alur Sederhana Aplikasi

  1. Pengguna membuka aplikasi.
  2. Jika belum login, pengguna diarahkan ke halaman login.
  3. Setelah login, token disimpan di memory dan data user disimpan di localStorage.
  4. Pengguna masuk ke dashboard.
  5. Pengguna memilih project dari sidebar.
  6. Pengguna membuat, melihat, mengubah, atau memindahkan task.
  7. Frontend mengirim perubahan ke backend API.
