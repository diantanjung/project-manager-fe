Testing, Build, dan Preview

Setelah fitur selesai dibuat, project perlu dicek. Tujuannya agar kita tahu aplikasi masih berjalan dan tidak ada kesalahan besar.

1. Menjalankan Test

Project ini memakai Vitest. Jalankan: 

npm run test

Test berada di beberapa file seperti:

  • src/services/*.test.ts
  • src/stores/*.test.ts
  • src/pages/*.test.tsx
  • src/components/**/*.test.tsx

2. Menjalankan Lint

Lint membantu menemukan pola kode yang kurang rapi atau berpotensi salah. 

npm run lint

3. Build Production

Build membuat versi aplikasi yang siap ditempatkan di hosting. 

npm run build

Script build project ini menjalankan TypeScript build dulu, lalu Vite build: 

tsc -b && vite build

4. Preview Build

Setelah build selesai, jalankan preview untuk melihat hasil production secara lokal. 

npm run preview

5. Checklist Sebelum Deploy

  • .env sudah mengarah ke backend API yang benar.
  • Login berhasil.
  • Dashboard berhasil memuat data.
  • Project bisa dibuat dan dibuka.
  • Task bisa dibuat, diedit, dipindah status, dan dihapus.
  • Halaman admin hanya bisa dibuka oleh admin.
  • npm run test berhasil.
  • npm run build berhasil.
