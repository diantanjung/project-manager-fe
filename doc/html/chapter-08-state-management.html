State Management dengan Zustand

State adalah data yang sedang dipakai aplikasi. Contohnya: user yang login, daftar project, daftar task, loading, error, dan pagination.

Kenapa Memakai Store?

Tanpa store, data harus dikirim dari satu komponen ke komponen lain secara manual. Semakin besar aplikasi, cara itu menjadi sulit. Zustand membantu membuat tempat penyimpanan data yang bisa dipakai banyak komponen.

Pola Store di Project Ini

Hampir semua store punya pola yang mirip:

  1. Simpan data utama, misalnya projects atau tasks.
  2. Simpan status loading, error, page, total, dan limit.
  3. Buat action seperti fetch, create, update, delete.
  4. Action memanggil service API.
  5. Setelah API berhasil, store memperbarui state.

Contoh Project Store

src/stores/projectStore.ts menyimpan daftar project dan action untuk mengambil, membuat, mengubah, dan menghapus project. 

fetchProjects: async (params) => {
  set({ isLoading: true, error: null });
  try {
    const response = await projectService.getAllProjects(params);
    set({
      projects: response.data,
      total: response.pagination.totalItems,
      page: response.pagination.page,
      totalPages: response.pagination.totalPages,
      isLoading: false,
    });
  } catch {
    set({ error: "Failed to fetch projects", isLoading: false });
  }
}

Contoh Task Store

src/stores/taskStore.ts menyimpan task dan punya fungsi moveTask. Fungsi ini dipakai saat user memindahkan task di board.

Saat task dipindahkan, UI langsung berubah dulu. Cara ini disebut optimistic update. Setelah itu frontend mengirim perubahan ke backend.
