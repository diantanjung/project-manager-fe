Membuat Project Vite

Project ini dibuat dengan Vite. Vite membantu React berjalan cepat saat development dan membuat hasil build untuk production.

1. Buat Project Baru

Jika membuat dari benar-benar nol, jalankan perintah berikut: 

npm create vite@latest project-manager-fe -- --template react-ts

Perintah itu membuat project bernama project-manager-fe dengan template React dan TypeScript.

2. Masuk ke Folder Project

cd project-manager-fe

3. Install Dependency

npm install

4. Install Library yang Dipakai Project Ini

Project ini memakai beberapa library tambahan untuk routing, API, state, style, form, icon, drag and drop, dan testing. 

npm install react-router zustand axios tailwindcss @tailwindcss/vite react-hook-form react-icons react-select @hello-pangea/dnd
npm install -D vitest jsdom @testing-library/react @testing-library/jest-dom eslint typescript-eslint

5. Atur Script di package.json

File package.json project ini memiliki script berikut: 

"scripts": {
  "dev": "vite",
  "build": "tsc -b && vite build",
  "lint": "eslint .",
  "test": "vitest run",
  "preview": "vite preview"
}

6. Jalankan Development Server

npm run dev

Biasanya Vite akan menampilkan alamat seperti http://localhost:5173. Buka alamat itu di browser untuk melihat aplikasi.

7. Konfigurasi Vite

File vite.config.ts project ini memakai plugin React SWC, plugin Tailwind CSS, dan konfigurasi test. 

import { defineConfig } from "vitest/config";
import react from "@vitejs/plugin-react-swc";
import tailwindcss from "@tailwindcss/vite";

export default defineConfig({
  plugins: [react(), tailwindcss()],
  test: {
    environment: "jsdom",
    setupFiles: "./src/test/setup.ts",
  },
});
