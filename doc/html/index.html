Project Manager Frontend

Tutorial Pembuatan Project dari Awal sampai Akhir

Dokumentasi ini menjelaskan cara membangun project frontend TaskFlow/Project Manager dari nol. Bahasanya dibuat sederhana agar orang awam bisa mengikuti alurnya: mulai dari menyiapkan komputer, membuat project React, menyusun folder, menghubungkan API, membuat halaman, sampai menjalankan test dan build.

Tutorial ini mengikuti struktur project yang ada di repository ini: React, TypeScript, Vite, Tailwind CSS, React Router, Zustand, Axios, dan Vitest.
