Login, Register, dan Proteksi Halaman

Authentication adalah proses memastikan pengguna sudah masuk ke aplikasi. Jika belum login, pengguna tidak boleh membuka dashboard atau halaman project.

1. Halaman Login

File src/pages/Login.tsx menampilkan form email dan password. Saat tombol Sign In ditekan, fungsi authService.login dipanggil.

  1. User mengisi email dan password.
  2. Frontend mengirim data ke endpoint /auth/login.
  3. Backend mengembalikan user dan access token.
  4. Store menyimpan user dan token.
  5. User diarahkan ke dashboard atau halaman asal.

2. Auth Store

File src/stores/authStore.ts menyimpan informasi login. User disimpan di localStorage, sedangkan access token disimpan di memory melalui setAccessToken.

Access token tidak disimpan di localStorage agar lebih aman. Jika halaman refresh, frontend meminta token baru memakai refresh token dari cookie HttpOnly.

3. Protected Route

File src/components/ProtectedRoute.tsx menjaga halaman yang harus login. Kalau user belum login, pengguna diarahkan ke /login. 

return isAuthenticated ? (
  <Outlet />
) : (
  <Navigate to="/login" replace />
);

4. Proteksi Role Admin

Beberapa halaman hanya boleh dibuka oleh admin, yaitu:

  • /admin/users
  • /admin/teams

Jika user bukan admin, aplikasi mengarahkan user kembali ke dashboard.

5. Logout

Saat logout, aplikasi memanggil endpoint /auth/logout, menghapus token dari memory, menghapus user dari localStorage, lalu mengarahkan pengguna ke halaman login.
