Routing dan Layout

Routing adalah aturan halaman. Saat pengguna membuka alamat tertentu, React Router menentukan komponen apa yang harus tampil.

1. Entry Point Aplikasi

File src/main.tsx adalah pintu masuk aplikasi. Di sini React menempelkan aplikasi ke elemen HTML dengan id root. 

createRoot(document.getElementById("root")!).render(
  <StrictMode>
    <App />
  </StrictMode>
);

2. Daftar Route

File src/App.tsx membuat router dengan createBrowserRouter. Project ini punya halaman publik dan halaman yang harus login.

Route Halaman
/loginHalaman login
/registerHalaman register
/dashboardDashboard utama
/project/:projectIdBoard dan list task per project
/profileProfil user
/admin/usersManajemen user khusus admin
/admin/teamsManajemen team khusus admin

3. Layout Utama

File src/layouts/MainLayout.tsx membuat tampilan dasar setelah login: sidebar di kiri, header di atas, dan konten halaman di area utama. 

<div className="flex h-screen w-full">
  <Sidebar />
  <main>
    <PageHeader />
    <Outlet />
  </main>
</div>

Outlet adalah tempat anak route ditampilkan. Misalnya, ketika route adalah /dashboard, maka komponen Dashboard muncul di posisi Outlet.

4. Sidebar

Sidebar menampilkan menu Dashboard, Users, Teams, dan daftar project. Menu Users dan Teams hanya muncul untuk user dengan role admin.
