Persiapan Komputer

Sebelum membuat project, komputer perlu memiliki beberapa alat dasar. Anggap saja seperti menyiapkan meja kerja sebelum mulai membangun.

1. Install Node.js dan npm

Node.js dipakai agar kita bisa menjalankan tool JavaScript di komputer. npm biasanya ikut terinstall bersama Node.js. Setelah install, cek versinya: 

node -v
npm -v

2. Install Code Editor

Gunakan editor seperti Visual Studio Code, WebStorm, atau editor lain yang nyaman. Editor dipakai untuk membuka folder project dan mengubah file.

3. Siapkan Terminal

Terminal adalah tempat menjalankan perintah seperti install dependency, menjalankan server, test, dan build.

4. Siapkan Backend API

Frontend ini butuh backend API. Secara default, project mengarah ke: 

http://localhost:8000/api/v1

Jika backend belum berjalan, halaman mungkin terbuka, tetapi data seperti login, project, task, dan dashboard tidak akan berhasil dimuat.

5. Buat File Environment

Buat file .env di root project untuk menentukan alamat backend. 

VITE_API_URL=http://localhost:8000/api/v1
Semua environment variable yang ingin dibaca oleh Vite di browser harus diawali dengan VITE_.
