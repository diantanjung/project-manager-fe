Struktur Folder

Struktur folder membantu project tetap rapi. Setiap jenis file punya rumahnya masing-masing, sehingga orang baru bisa lebih mudah mencari file.

Struktur Utama

src/
  components/
  features/
  hooks/
  layouts/
  lib/
  pages/
  services/
  stores/
  test/
  types/
  utils/

Penjelasan Folder

Folder Isi
components Komponen UI yang bisa dipakai ulang, seperti modal, sidebar, task card, dan list.
pages Halaman utama yang dihubungkan ke route, seperti Login, Dashboard, dan ProjectBoard.
layouts Kerangka halaman, misalnya layout yang berisi sidebar dan header.
services Tempat fungsi untuk memanggil backend API.
stores Tempat state global menggunakan Zustand.
types Definisi tipe data TypeScript, misalnya tipe User, Project, Task, dan Team.
lib Konfigurasi library, contohnya konfigurasi Axios di src/lib/axios.ts.
utils Fungsi kecil yang membantu kebutuhan tertentu, seperti format avatar atau API error.

Alur File Saat Fitur Dibuka

Contoh saat pengguna membuka halaman project:

  1. src/App.tsx membaca route /project/:projectId.
  2. React Router menampilkan src/pages/ProjectBoard.tsx.
  3. Halaman memanggil useTaskStore dari src/stores/taskStore.ts.
  4. Store memanggil taskService dari src/services/task.service.ts.
  5. Service mengirim request ke backend memakai Axios.
  6. Data task diterima lalu ditampilkan sebagai card atau list.
